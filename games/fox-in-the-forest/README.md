# The Fox in the Forest Deluxe

A card box for the sleeved deck (`box.scad`), a card-sized score tracker that
stores in it (`score.scad`), and reference cards to print on paper
(`reference.typ`).

## Fonts

Generating the score tracker needs
[TeX Gyre Bonum](https://www.gust.org.pl/projects/e-foundry/tex-gyre)
installed; without it, OpenSCAD sets the numbers in another font.
