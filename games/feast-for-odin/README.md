# A Feast For Odin Insert

This is an insert for A Feast For Odin with The Norwegians expansion.

There are several other nice inserts, but I wanted scoop bins for the goods
tiles and a nice supply board for the special tiles, similar to the one in the
base game, but now with indents for the pieces.

## Printing

All multi-color settings aren't really required, and are not recommended unless
you have a tool-changer.

Plates are arranged so you can set the "setup" inserts a different color than
the ones used during the game.

I recommend you use adaptive layer heights; this should help the scoops be
smooth while letting you have large layers above them. If you want clear text
for the symbols on the tile scoops, though, those should be at a lower layer
height; I set mine to around 0.16, whereas Orca wanted to put them closer to 0.3.
