# A Feast For Odin Insert

This is an insert for A Feast For Odin with The Norwegians expansion.

There are several other nice inserts, but I really wanted one that met these
constraints:

1. Scoop bins for the goods tiles. I'm just not neat enough to keep them all
   nicely stacked.
2. Two sets of most goods tiles. I find this really helps with reach, so they're
   not constantly having to be passed around.
3. Bring back the supply board for special tiles. The base game had a nice board
   with a perfect location for each special tile, and the expansion dumped it.
   Now, we can get it back better than ever, with detents so it also acts as the
   storage for these tiles.

I did my best to structure the layout so they're easy to put away and to waste
as little space as possible. There are two honeycomb spacers to cover the space
I could not avoid wasting, and the building trays have less tolerance than
everything else to get them to fit nicely.

## Pieces Replaced

This insert replaces the boat supply board and the special tile boards; it is
not intended you keep them in the box.

## Printing

The Orca project is laid out for my Snapmaker U1 with a 270 mm square bed. The
frame halves are each about 152 x 217 mm; this is the largest piece to print.

It has a few slicer settings baked in:
* `reduce_infill_retraction` to try to stop stringing across pinch slots; it's
  questionable how much this actually helps.
* The island and setup building trays set `wall_sequence` to outer wall first to
  attempt to prevent bulging where the floor ends.

The project is set up so that "setup trays" (those not used during gameplay) are
printed a separate color than the ones you use during the game.

Multicolor is optional, but if you'd like it:
* There are labels on the side of the goods tiles and money bins to show their
  shape.
* There's a two-color forge icon on the small special tray for the forgeable
  tiles.
* The special boards' pocket floors are set to print in a second color if you
  want to make them **pop**.

I recommend variable layer height for the scoop bins, so you can get a nice
smooth curve at the bottom without taking forever to print them.

The buildings tray is printed sideways, with a separate end cap. Glue it on with
a little gel CA.

If you're not using the Orca project, print two each of:
* frame
* half_a
* half_b
* weapon card tray (one is used for the setup occupation cards, so I print it in
  the setup color)

Nothing should need to be printed with supports.

## Notes

The card trays are sized for sleeved cards.

## Assembly

Put the two U-shaped frame pieces in first. In them, place the misc large
cardboard pieces (I recommend small to big as you go, so it's easier to lift
them out), and then the frame supports the player boards.

The 4 goods bins (2 of each size) and special tile boards are each a full level.

Above these, everything is laid out in two columns:

The skinny column is divided into:
1. A long portion, with the decks on top:
   * The mountain strips
   * All the decks
2. A short portion, in any order:
   * The boats and misc bin (for moose and dice)
   * The Victory Point/Penalty/Money tray with the small hexagon spacer

The wider column is divided into:
1. A square portion with, in any order (though it's recommended to put the
  buildings tray on top):
   * The islands
   * The setup buildings with the larger honeycomb spacer
   * The buildings tray
2. A rectangular portion, in any order:
   * The large goods tiles/animals
   * The wood/ore/stone tray and the vikings tray

I recommend placing the rulebooks on the very top.
