# SET

A card box for the deck (`box.py`): purple, with three cards on its front,
and a lavender lid with the logo in its top.

## Fonts

Generating the box needs
[TeX Gyre Termes](https://www.gust.org.pl/projects/e-foundry/tex-gyre)
installed; without it, build123d sets the logo's letters in another font.
