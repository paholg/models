# Card trays

The files in this directory are not original to this repository.

**Remixed A Feast for Odin card trays** by DewLeen
([@DewLeen_91662](https://www.printables.com/@DewLeen_91662) on Printables),
<https://www.printables.com/model/1145265-remixed-a-feast-for-odin-card-trays>,
published 2025-01-12.

It is a remix of **A Feast for Odin (+exp) Organizer / Insert** by RiftForge 3D
([@RiftForge3D3](https://www.printables.com/@RiftForge3D3) on Printables).

The files are unmodified from the Printables download:

* `occupation_cards_tray.stl`: the in-game occupation cards.
* `weapon_cards_tray_x2.stl`: print twice, for the weapon cards and the setup
  occupation cards.

`../layout.scad` imports the STLs, unchanged, to place them in the box. The
